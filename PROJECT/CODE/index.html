Why two regression models?

01

Ridge Regression

L2 REGULARISATION

Ridge adds a penalty based on squared coefficients. It shrinks large coefficients and helps manage correlated travel features.

Loss = Σ(y − ŷ)² + λΣβ²
StabilityMulticollinearity controlGeneralisation
02

Lasso Regression

L1 REGULARISATION

Lasso uses the absolute values of coefficients. Less important features can reach zero, providing implicit feature selection.

Loss = Σ(y − ŷ)² + λΣ|β|
Feature selectionSimpler modelGeneralisation
